# 常见问题与报错对照（anan-wechat-article）

## 1. 报错文案对照表

| 你会看到 | 原因 | 怎么办 |
| --- | --- | --- |
| `这不是微信公众号文章链接（域名是 xxx）` | 链接不是 `mp.weixin.qq.com` | 换正确的公众号文章链接。**不要**为了绕过加 `--allow-any-url` |
| `微信返回了拦截/错误页（命中关键词「环境异常」）` | 触发风控，微信要求验证 | 停一会儿（几分钟到几小时），加大 `--delay`，减少单次批量；不要在微信里手动过验证的同时继续跑 |
| `微信返回了拦截/错误页（命中关键词「该内容已被发布者删除」）` | 文章被删 | 换链接，无解 |
| `页面里没有找到 id=js_content 的正文容器` | 分享卡片页、被删文章、需要登录的内容 | 换链接；或用浏览器打开确认能否正常阅读 |
| `封面图下载失败（表格里记原始链接）` | 防盗链或网络抖动 | 不影响正文；重跑一次通常就好 |
| `图片下载失败（保留原链接）` | 同上 | 正文里保留原始 URL，可重跑 |
| `正文解析为空，请在报告里如实标注` | 页面结构异常/正文为空 | 打开链接人工确认；这是实情，**不要**编造内容 |
| 作者显示「未获取」 | 该公众号未单独署名 | 正常现象，不是故障 |
| 发布时间「未获取」 | 页面脚本变量缺失 | 少数文章会这样，如实标注 |
| 退出码 2 | 没给链接 | 补上 URL 或 `--urls-file` |
| 退出码 1 | 全部失败 | 看失败原因逐条处理 |

## 2. 高频疑问

**Q：能抓到阅读量、点赞、在看、收藏、评论吗？**
不能。这些数字是登录后在客户端由 JS 异步填的，静态页面里没有；脚本也不输出这些字段。需要这类数据只能人工看，或走公众号后台/第三方平台。**不要向用户承诺能抓。**

**Q：能抓某个公众号的全部历史文章吗？**
不能。本技能只抓**已知链接**的单篇，没有列表/翻页接口。需要用户先提供链接清单。

**Q：能抓留言区内容吗？**
不能，留言不在静态页面里。

**Q：为什么正文里出现「🎧 此处为公众号语音」「📇 此处为公众号名片」这种句子？**
语音、视频、视频号、小程序卡片、内嵌 iframe、QQ 音乐等在静态页面里拿不到内容，脚本如实留占位说明，并把类型记到 `meta.json` 的「未抓取到的富媒体」。这是**如实标注，不是故障**。

**Q：能一次跑几千篇吗？**
不要。会触发风控并给对方服务器压力。几十篇一次、分批分时段，`--delay≥5`。

**Q：图片下载不全怎么办？**
正文里保留了原始链接，重跑一次即可补齐；也可以 `--no-images` 只留文字。

**Q：抓下来的文章能直接发到我的号上吗？**
**不能，那是侵权**（正文和图片版权都不属于你）。抓取结果仅用于自用素材、分析与归档；引用要注明出处 + 原文链接，转载/商用必须获得授权。

## 3. 环境相关

- 需要 Python 3.8+；脚本零第三方依赖，`python -S` 也能跑。
- 需要能访问 `mp.weixin.qq.com` 与 `mmbiz.qpic.cn`。
- 控制台中文乱码：脚本会自动把 stdout/stderr 设为 UTF-8；如仍乱码，用 `chcp 65001` 或换终端。
- 输出目录默认是**当前工作目录**下的 `output`，不是脚本所在目录；建议始终用 `-o` 明确指定。
